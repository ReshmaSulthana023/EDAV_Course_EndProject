
# 📊 Disease Incidence Rate Analysis — EDAV 2025 Project

## 🧪 Project Overview
This project focuses on analyzing **disease incidence rates across Indian states and years** for key diseases.  
It was developed as part of the **EDAV (Exploratory Data Analysis and Visualization)** course project (CEP-17, 2025).

The main goal is to:
- Explore how disease incidence varies across different states.
- Analyze temporal trends in reported cases.
- Create clear and insightful visualizations.
- Identify high-risk regions and time periods for key diseases.

---


- **`.ipynb`** → Main Jupyter Notebook containing data cleaning, analysis, and visualization.  
- **`.gitattributes`** → Ensures consistent LF line endings for notebook files.  
- **`README.md`** → Project documentation.

---

## 🛠️ Tech Stack
- 🐍 Python  
- 📓 Jupyter Notebook  
- 📊 Pandas  
- 📈 Matplotlib, Seaborn

---

## 📊 Key Features
- Data preprocessing and cleaning of disease datasets.  
- Time-series analysis of incidence rates.  
- State-wise comparison of disease spread.  
- Visualizations using bar plots, line charts, and heatmaps.  
- Insights and trends identified over multiple years.
